The pre-registered test on fresh data

Four hypotheses were committed to GitHub before any 2025–2026 prices were downloaded, then tested once on January 2025 to September 2026. A hypothesis is supported or contradicted only if one side wins in at least 95% of resamples.

How the test was run

Universes
SPY, AAPL, MSFT, JPM, XOM and KO, chosen by hand; and the 29 stocks of the Dow Jones index as of January 2014, picked without hindsight. Each symbol is backtested on its own with $100,000.
Selection
One parameter set per strategy, chosen by average Sharpe ratio on 2014–2019, then run unchanged on 2020–2024.
Fills
Decide on the close, fill at the next day's open. Strategies only see bars up to the current one.
Costs
0.1% commission and 5 bps slippage on every buy and sell. Idle cash earns no interest.
Data
Daily prices from Tiingo, adjusted for splits and dividends. This page holds summary statistics only, no prices.
Caveats
The six symbols were chosen with hindsight, which flatters every approach. Each symbol has few trades per period, so averages across symbols mean more than any single row. The fresh-data test covers only 21 months.
